# Controlled Evaluation of Trapping-Set Screening in QC-LDPC Codes

**Research Portfolio | Algorithm Evaluation | Graph Analysis | Scientific Computing | Statistical Analysis**

**Research Status:** Manuscript in preparation.

## Project Overview

Low-density parity-check (LDPC) codes are used in reliable digital communication. Their performance can be affected by small structures in the associated Tanner graph, including trapping sets.

This research examines how **structural screening rules for irregular quasi-cyclic LDPC (QC-LDPC) codes** should be evaluated. A key challenge is that codes passing and failing a screen may also differ in other graph characteristics. Without controlling those differences, an apparent performance gap may not isolate the characteristic being studied.

The project combines graph-based screening, communication-channel simulations, and statistically controlled comparisons to study this evaluation problem.
